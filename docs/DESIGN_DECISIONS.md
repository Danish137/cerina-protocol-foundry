# Design Decisions

| # | Decision | Why | Trade-off | Where in code |
|---|---|---|---|---|
| 1 | **Fail-closed safety rubric** | A self-help exercise must never look "approved" or "ready" if safety or quality checks crashed, timed out, or returned `unavailable`. | Interrupted or rate-limited runs require an explicit re-check (`recheck_required=True`) instead of letting users approve immediately. | [`backend/runner.py`](../backend/runner.py), [`backend/main.py`](../backend/main.py), [`backend/hosted_mcp.py`](../backend/hosted_mcp.py) |
| 2 | **Writer vs. reviewer model families** | A model grading its own output can miss systematic blind spots; barring same-family grading forces cross-family review. | Requires maintaining keys and rate-limit configs for two independent provider families. | [`backend/config.py`](../backend/config.py), [`backend/llm_client.py`](../backend/llm_client.py) |
| 3 | **Evidence-quote check** | Requiring the quality reviewer to attach verbatim quotes from the draft reduces generic rubber-stamping. | Slightly larger structured JSON responses from the reviewer and occasional schema retries. | [`backend/rubrics.py`](../backend/rubrics.py), [`backend/agents/agents.py`](../backend/agents/agents.py) |
| 4 | **Human approval as final gate** | AI reviewers catch structural and safety issues, but the user reads, edits, and explicitly approves before locking and exporting PDF. | Adds a required human step (`awaiting_approval` → `approved`) rather than auto-finalizing. | [`backend/agents/workflow.py`](../backend/agents/workflow.py), [`frontend/src/components/ActionPanel.tsx`](../frontend/src/components/ActionPanel.tsx) |
| 5 | **Append-only events + SSE with polling fallback** | Live token streaming keeps perceived wait short, while durable `(session_id, seq)` rows let clients recover cleanly from dropped SSE connections or page refreshes. | Dual transport logic (live SSE + `/events?after=` and `/state` polling) adds client state reconciliation complexity. | [`backend/database.py`](../backend/database.py), [`frontend/src/services/sseClient.ts`](../frontend/src/services/sseClient.ts) |
| 6 | **Single-worker registry** | Holding active `asyncio.Task` handles and SSE subscriber queues in one process prevents duplicate concurrent runs per session without Redis. | Cannot horizontally scale backend replicas without moving task locks and pub/sub to an external broker (e.g. Redis + Postgres). | [`backend/runner.py`](../backend/runner.py) |
| 7 | **Hashed tokens, no accounts** | Lower friction for a self-help demo and zero PII/passwords stored; raw `session_token` is returned once and compared via SHA-256 + `hmac.compare_digest`. | If a user clears browser storage and loses the token, the session cannot be recovered; missing/wrong tokens return `404`. | [`backend/security.py`](../backend/security.py), [`frontend/src/services/sessionStorage.ts`](../frontend/src/services/sessionStorage.ts) |
| 8 | **Capacity guard + MCP per-IP limits** | Protects free-tier daily quotas globally (`/api/capacity`) and prevents a single external MCP client from exhausting daily runs or spinning infinite revisions. | Shared NAT/hosting IPs can cause legitimate MCP users to share a per-IP quota bucket. | [`backend/security.py`](../backend/security.py), [`backend/hosted_mcp.py`](../backend/hosted_mcp.py) |
| 9 | **Deterministic crisis flow** | Crisis detection must be instant, predictable, and independent of LLM availability—routing straight to localized helplines and keeping a static helpline block inside `ErrorBoundary`. | Keyword matching can occasionally trigger on non-crisis phrasing, intentionally erring on the side of caution. | [`backend/crisis.py`](../backend/crisis.py), [`frontend/src/components/ErrorBoundary.tsx`](../frontend/src/components/ErrorBoundary.tsx) |
| 10 | **Hosted MCP inside the same app** | Mounting Streamable HTTP `/mcp` inside the existing FastAPI lifespan shares the same SQLite DB, `RunnerRegistry`, crisis screen, and token auth with zero extra service to deploy. | Shares process memory and rate-limit fate with the web API; still bound to single-worker deployment. | [`backend/hosted_mcp.py`](../backend/hosted_mcp.py), [`backend/main.py`](../backend/main.py) |
