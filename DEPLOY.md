# Cerina Protocol Foundry — Deployment & Environment Configuration

This document provides deployment guidelines, required environment variables, rate limits, and provider failover policies for Cerina Protocol Foundry.

---

## 1. Environment Variables Reference

Cerina Protocol Foundry uses **neutral `LLM_*` environment variable names** (Round 5 Amendment 7), with automatic backwards-compatibility fallbacks to legacy `OPENAI_*` names.

### API Keys
| Variable | Required / Optional | Description |
|---|---|---|
| `GROQ_API_KEY` | **Required** (for primary writer) | GroqCloud API key for ultra-fast LPU inference (`openai/gpt-oss-120b`). |
| `GOOGLE_API_KEY` | **Required** (for primary judge) | Google AI Studio API key for Gemini inference (`gemini-3.1-flash-lite`). |
| `OPENROUTER_API_KEY` | Optional (last resort) | OpenRouter API key used as the final safety net fallback. |
| `OPENAI_API_KEY` | Optional (fallback) | Alias for OpenRouter or OpenAI API key. |

### Model & Provider Configuration
| Neutral Variable | Default Value | Legacy Fallback | Purpose |
|---|---|---|---|
| `LLM_WRITER_PROVIDER` | `groq` | `WRITER_PROVIDER` | Primary protocol drafting provider. |
| `LLM_WRITER_MODEL` | `openai/gpt-oss-120b` | `OPENAI_WRITER_MODEL` | Primary protocol drafting model (~4.0s generation). |
| `LLM_WRITER_FALLBACK_PROVIDER` | `gemini` | — | Fallback drafter if Groq is unavailable. |
| `LLM_WRITER_FALLBACK_MODEL` | `gemini-3.1-flash-lite`| — | Fallback drafting model. |
| `LLM_JUDGE_PROVIDER` | `gemini` | `JUDGE_PROVIDER` | Primary clinical & safety judge provider. |
| `LLM_JUDGE_MODEL` | `gemini-3.1-flash-lite` | `OPENAI_JUDGE_MODEL` | Primary judge model (100% canary accuracy, ~1.4s). |
| `LLM_JUDGE_FALLBACK_PROVIDER` | `groq` | — | Fallback judge provider. |
| `LLM_JUDGE_FALLBACK_MODEL` | `qwen/qwen3.8-27b` | — | Fallback judge model (0.5s latency). |
| `LLM_LAST_RESORT_PROVIDER` | `openrouter` | — | Emergency tertiary failover provider. |
| `LLM_LAST_RESORT_MODEL` | `openrouter/free` | `OPENAI_MODEL` | Emergency tertiary model. |

### Application & Database Configuration
| Variable | Default Value | Description |
|---|---|---|
| `DATABASE_URL` | `sqlite:///./cerina_foundry.db` | SQLite database URI for sessions, events, and LangGraph checkpoints. |

## 2. Zero Same-Family Self-Grading Rule (Amendment 2)

To maintain strict clinical independence, the unified LLM client router enforces that **an AI model never grades its own family's output**:
* If the draft was generated by **Groq** (`openai/gpt-oss-120b`), judges are routed to **Google Gemini** (`gemini-3.1-flash-lite`).
* If the drafter fails over to **Gemini**, the judge automatically switches to **Groq** (`qwen/qwen3.8-27b`).
* Gemini never grades Gemini; Groq never grades Groq.

## 3. Measured Free-Tier Rate Limits & Capacity

Limits have been empirically probed and verified:
* **Groq Free Tier**:
  * **Requests Per Day (RPD)**: `1,000` (**MEASURED** via `x-ratelimit-limit-requests: 1000`)
  * **Tokens Per Minute (TPM)**: `8,000` (**MEASURED** via `x-ratelimit-limit-tokens: 8000`)
  * Pre-flight limiter automatically switches to Gemini fallback if sliding-window tokens exceed 7,500.
* **Google Gemini Free Tier**:
  * **Requests Per Minute (RPM)**: `15` (**MEASURED** via live burst probe)
  * **Tokens Per Minute (TPM)**: `1,000,000` (Assumed specification)
  * **Requests Per Day (RPD)**: `1,500` (Assumed specification)

**Live runs left today** is computed in `/api/capacity` from the tightest measured limit (`1000 - today_calls`).

## 4. Local & Production Deployment

### Backend Setup
```bash
cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt

# Start production server
uvicorn main:app --host 0.0.0.0 --port 8000
```

### Frontend Setup
```bash
cd frontend
npm install
npm run build
npm run preview -- --port 3000
```
